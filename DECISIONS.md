# Decisions

1. **Static site on GitHub Pages, Python build, no framework.** The prototype was one HTML file with an embedded dataset;
   the only server-side need was refreshing data, which scheduled Actions do. Everything else stays in the browser.
2. **Neutral benchmark.** The prototype's October 7 reference row read as ranking victims of a political event (the
   evaluator flagged it). Shark attacks are the classic case of attention far beyond toll, with an authoritative yearly
   count (International Shark Attack File, 12 confirmed deaths in 2025).
3. **Indexed launch.** No live original exists (howcouldihelp.com is a parking page), so nothing is duplicated.
4. **Attention = human pageviews, 12 complete months, up to four articles per cause.** `agent=user` drops identified bots;
   summing a few articles avoids penalising causes whose readers are spread across titles. Every article is listed.
5. **Tolls are copied, quoted and re-checked, never estimated.** A short quoted phrase per figure (≤15 words) lets a job
   verify it weekly; a revised figure is flagged "under review" instead of being kept silently.
6. **The scoring function is the prototype's, unchanged.** Rarity and scale still multiply every cause equally, so they
   never change the winner; the method page says so instead of pretending otherwise.
7. **Public record through GitHub issues.** It is opt-in, public, under the visitor's own account, needs no database and
   gives the falsifier a real count. Issues labelled invalid/spam/duplicate are not counted.
8. **No brand or operator name.** The prototype said "Persist Ventures"; publishing under Jack's brand needs his say, so
   the site names no operator. The "war room" label stays.
9. **Organisations are listed, not contacted.** The evaluator's cheapest test (email three organisations) needs a person;
   it is a key in OPERATIONS.md. Every listing says the organisation does not run or endorse the board.
10. **Safe messaging for suicide.** No method details, crisis resources on the page, the card and the assignment, and no
    shark comparison on that cause.
